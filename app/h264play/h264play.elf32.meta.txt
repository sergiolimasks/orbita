Pipeline (P7.2 — 2-core)
  H.264 stream (TCP length-prefix live OR embedded fallback)
  -> libavcodec pure-C decode (main thread, core 0)
  -> memcpy planes -> ring slot -> ready=1 (release barrier eieio+sync)
  -> WORKER (thread 2, core 1 primary)
     acquire barrier (lwsync) -> BT.601 YUV->RGB -> direct-FB tiled write

Report line: [play] t+Ns dec=X prod=X w_cvt=X fps=X w_frames=N ring=NB
  dec     = libavcodec decode time / frame (main)
  prod    = memcpy + backpressure wait / frame (main)
  w_cvt   = worker YUV->RGB conversion time / frame (cumulative avg)
  w_frames= total frames converted by worker so far
  ring    = TCP ring buffer bytes pending (backpressure indicator)

Speedup hypothesis vs v0.7.0 inline:
  v0.7.0: dec + cvt sequential -> tot ≈ dec + cvt
  v0.8.0: dec || w_cvt in parallel -> tot ≈ max(dec + prod, w_cvt)
  Expected fps improvement: 1.5-1.8x if dec ≈ cvt (typical case)
